# TechPrice

Мобильное приложение на Flutter для сравнения цен на электронику и бытовую
технику в интернет-магазинах Молдовы (Bomba, Maximum и др.). Пользователь
видит предложения разных магазинов по одному товару, историю цены и может
отслеживать товар до нужной цены.

Курсовой проект по дисциплине «Программирование мобильных приложений» (PAM),
UTM, группа TI-237. Автор — Мигов Даниил.

## Возможности

- регистрация и вход (JWT), токен хранится в защищённом хранилище ОС;
- каталог с поиском и постраничной загрузкой (поиск и пагинация на сервере);
- карточка товара: характеристики, цены по магазинам, график истории цены;
- избранное с целевой ценой («сообщить, когда подешевеет до …»);
- список покупок;
- список магазинов;
- обработка ошибок сети с повтором запроса.

## Стек

| Часть      | Технологии                                                     |
|------------|----------------------------------------------------------------|
| Приложение | Flutter, Provider (состояние и DI), go_router, http            |
| Хранение   | flutter_secure_storage (токен)                                 |
| Сервер     | Python 3, FastAPI, SQLite, PyJWT, bcrypt — см. [`server/`](server/README.md) |

## Структура

```
lib/
  data/      — модели данных, API-клиент, репозитории (интерфейс + HTTP-реализация)
  models/    — ChangeNotifier-модели состояния экранов
  screens/   — экраны
  widgets/   — переиспользуемые виджеты
  utils/     — форматирование и валидация
  router.dart, main.dart
server/      — backend на FastAPI
test/        — unit- и widget-тесты (с фейковыми репозиториями)
```

## Запуск

### 1. Сервер

```bash
cd server
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt   # один раз
.venv/bin/python -m app.main                                          # http://localhost:8080
```

### 2. Приложение

```bash
flutter pub get
flutter run                                   # эмулятор Android: сервер доступен как 10.0.2.2
```

Адрес сервера задаётся при сборке через `API_BASE`, по умолчанию
`http://10.0.2.2:8080` (это `localhost` компьютера, видимый из эмулятора).
Для реального телефона в той же Wi-Fi сети укажи IP компьютера:

```bash
flutter run --dart-define=API_BASE=http://192.168.1.50:8080
```
