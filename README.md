# TechPrice

Мобильное приложение на Flutter для сравнения цен на электронику и бытовую
технику в интернет-магазинах Молдовы (Bomba, Maximum и др.). Пользователь
видит предложения разных магазинов по одному товару, историю цены и может
отслеживать товар до нужной цены.

Курсовой проект по дисциплине «Программирование мобильных приложений» (PAM),
UTM, группа TI-237. Автор — Мигов Даниил.

## Возможности

- регистрация и вход (JWT), токен хранится в защищённом хранилище ОС;
- каталог с поиском по словам (название, бренд, артикул) и постраничной загрузкой;
- фильтры: категория, бренд, магазин, диапазон цены, только со скидкой, только товары
  из нескольких магазинов; сортировка по цене, скидке и названию;
- карточка товара: фото, цены по магазинам с переходом на сайт магазина, история цены;
- избранное с целевой ценой («сообщить, когда подешевеет до …»);
- список покупок;
- список магазинов;
- обработка ошибок сети с повтором запроса.

## Запуск

### 1. Сервер

На Windows вместо `.venv/bin/python` и `.venv/bin/pip` пиши `.venv\Scripts\python` и `.venv\Scripts\pip`.

```bash
cd server
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt   # один раз
.venv/bin/python -m app.main                                          # http://localhost:8080
```

Переменные окружения сервера:

| Переменная  | По умолчанию   | Назначение                                                  |
|-------------|----------------|-------------------------------------------------------------|
| `PORT`      | `8080`         | порт                                                        |
| `JWT_SECRET`| dev-значение   | секрет подписи токенов                                      |
| `DB_PATH`   | `server/app.db`| файл базы SQLite                                            |
| `SEED_DEMO` | `0`            | `1` — заполнить пустую базу демо-каталогом с выдуманными ценами |
| `AUTO_SCRAPE` | `1`          | `0` — выключить автоматический сбор цен                     |
| `SCRAPE_AT` | `04:00`        | время ежедневного сбора цен (по часам компьютера с сервером) |

Пока сервер запущен, он сам собирает цены со всех магазинов каждый день в
`SCRAPE_AT`, а если при запуске последние данные старше 20 часов — через
минуту после старта. Сбор идёт отдельным процессом (`python -m app.scrape all`),
сервер в это время продолжает отвечать. Журналы последних 14 запусков лежат в
`server/logs/`. Состояние сбора — `GET /sync`, запуск вручную — `POST /sync`
(в приложении: Профиль → Магазины → «Обновить»).

Каталог хранится в таблицах `products` (модель товара), `offers` (товар в
конкретном магазине с текущей ценой) и `price_snapshots` (история: новая
запись появляется только при изменении цены или наличия).

### Парсинг магазинов

Цены собираются со страниц категорий «Смартфоны» и «Ноутбуки» интернет-магазинов
maximum.md и ultra.md:

```bash
cd server
.venv/bin/python -m app.scrape all --dry-run --max-pages 1   # проверка: показать, не записывая
.venv/bin/python -m app.scrape all                           # все магазины, запись в базу
.venv/bin/python -m app.scrape ultra --category Смартфоны    # один магазин и категория
```

Парсер соблюдает robots.txt и делает паузу 1,5 с между запросами. Товары,
которых не оказалось на сайте при полном проходе, отмечаются как «нет в
наличии». Первый настоящий проход удаляет демо-каталог.

После каждого прохода предложения разных магазинов сводятся в общие товары.
Сначала находится модель: у смартфонов — по названию и объёму накопителя, у ноутбуков —
по коду модели (FA608UMI, 15IAX9), серии с поколением (ThinkPad T14 Gen 5) или линейке
MacBook. Затем внутри модели сравниваются характеристики из карточек обоих магазинов:
у ноутбуков процессор, оперативная память, накопитель и диагональ, у смартфонов
оперативная память и диагональ (кроме складных). Предложения объединяются, только если
все известные в обоих магазинах характеристики совпадают. Пересопоставить вручную и
получить отчёт:

```bash
.venv/bin/python -m app.rematch --report matching_report.txt
```

bomba.md закрыт защитой Cloudflare от автоматических клиентов; парсер для него
есть (`python -m app.scrape bomba`), но в `all` не входит.

Тесты сервера:

```bash
cd server
.venv/bin/pip install -r requirements-dev.txt   # один раз
.venv/bin/python -m pytest
```

### 2. Приложение

```bash
flutter pub get
flutter run                                   # эмулятор Android: сервер доступен как 10.0.2.2
```

Адрес сервера задаётся при сборке через `API_BASE`, по умолчанию
`http://10.0.2.2:8080` (это `localhost` компьютера, видимый из эмулятора).
Для реального телефона в той же Wi-Fi сети укажи IP компьютера:

```bash
flutter run --dart-define=API_BASE=http://192.168.1.50:8080
```
